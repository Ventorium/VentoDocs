# VentoDocs UI 设计规范（页面设计基线）

> 来源：用户提供的页面设计方案 + 设计参考图（2026-10-23）。
> 本文是前端实施的视觉与交互基线，与 `docs/03-conventions.md` 的 fe-coding 编码规范配合使用。

## 1. 设计方向

- 现代 SaaS 管理界面 + 轻量化文档工作台。
- 白色背景、浅灰分区、蓝色主色、清晰的文件层级、融入工作流的 AI 助手。
- 避免传统网盘的朴素感，也不做过度复杂的企业后台。
- 桌面端优先，兼顾平板与移动端。
- 全局结构：左侧主导航 + 顶部工具栏 + 主内容区；编辑页允许沉浸式布局。

### 1.1 设计 Token

| Token | 值 | 用途 |
|---|---|---|
| 主色 | `#2563EB` | 按钮、链接、选中态（ant `colorPrimary`） |
| 页面背景 | `#F7F8FA` | 全局底色 |
| 卡片 | `#FFFFFF` | 内容卡片、表格容器 |
| 正文 | 深灰 | `rgba(0,0,0,0.88)` 级 |
| 状态色 | 仅 success / warning / error | 不用状态色做装饰 |

- 组件统一：表格、面包屑、下拉菜单、右侧抽屉、确认弹窗、Toast。
- 默认信息密度适中，文件列表支持紧凑模式。

### 1.2 左侧主导航

- 固定宽度 220–240px，可折叠。
- 项：首页、我的文件、共享给我、最近使用、收藏、回收站、智能体（v2）；管理员额外显示"管理"入口（用户管理、审计、系统设置）。
- 导航下方或顶部提供全局搜索入口（v1 为文件名搜索，v2 扩展内容搜索）。

### 1.3 全局交互规则

- 文件操作优先用工具栏 + 行内菜单，不为每个动作开独立页面。
- 简单操作即时反馈；删除、权限变更、永久删除等危险操作必须二次确认。
- 文件锁定、无权限、索引处理中、保存失败等状态必须有明确 UI 提示。
- 前端禁用只是体验层，权限/锁定/版本一律由后端强制。
- 加载、空态、错误、无权限、锁定五类状态全部要有设计，不能只画正常流程。

## 2. 页面清单

### 2.1 文件管理首页（P0，核心页面）

布局：

- 顶部区域：全局搜索框、通知、用户头像、上传按钮、新建文件夹。
- 目录导航：面包屑 `首页 / 项目资料 / 产品设计`；列表视图 / 网格视图切换。
- 工具栏：上传、新建文件夹、排序、筛选、刷新。

文件列表列：名称 | 修改时间 | 大小 | 状态（锁定标记等）。

交互：

- 单击文件 → 打开预览或编辑页；双击目录 → 进入目录。
- 行内 `...` 菜单：重命名、移动、复制、下载、分享、锁定、版本历史、删除。
- 常用操作直接显示，低频操作收进 `...` 菜单。
- 多选 → 批量操作工具栏（移动、删除、下载）。
- 拖拽文件到目录 = 移动；拖入空白区域 = 上传；上传显示进度、失败原因与重试。
- 搜索支持文件名（v1）/内容（v2）；结果展示所在目录、类型、更新时间。
- 锁定文件显示锁图标 + 锁定人（悬停/详情面板）；无写权限时禁用写入按钮（后端仍强制校验）。

### 2.2 在线编辑页 + 右侧 AI 助手（P1 编辑器；AI 面板 v2）

- 顶部工具栏：返回文件列表、文件名 + 保存状态、锁定/解锁入口、版本历史、分享、AI 助手开关（v2）。
- 按文件格式加载对应编辑器工具栏（xlsx → Sheets 工具栏、docx → Docs 工具栏、pptx → Slides 工具栏）。
- 编辑状态提示：保存中 / 已保存 / 冲突。
- AI 面板（v2）：三个入口"问文档 / 修改文档 / 生成内容"；修改流程 = 生成建议 → 显示前后差异 → 用户选择应用/重新生成/放弃 → 服务端校验写权限、锁定、版本 → 保存并生成历史版本 + 触发索引。
- 无写权限或文件被他人锁定时，AI 仍可解释文档，但"应用"不可用。
- 窄屏时右侧面板改为抽屉。

### 2.3 全应用 Agent 页（v2）

- 左侧：知识来源目录树（多选、搜索、全选/取消、显示已选数量、移除单项）。
- 中间：对话区；每条回答含正文 + 来源文件名 + 相关段落/页码 + 点击来源打开文件。
- 顶部：Agent 名称、历史会话、新建会话；底部：输入框 + 发送。
- 规则：目录选择只限定检索范围，不授予额外权限；无可靠证据时明确告知，不编造。

### 2.4 目录权限管理（P0）

- 入口：目录行菜单 → 权限管理（或目录详情）。
- 弹窗：标题"目录权限" + 目录名称及路径。
- 内容：已授权用户/团队列表、添加用户或团队、权限选项（读取、下载、上传、新建、修改、删除、分享、网站开放；v2 预留 Agent 读/写）。
- 始终显示提示："此权限适用于整个目录及其子目录。"
- 删除授权需二次确认；保存时后端校验操作者是否有权管理该目录。
- 目录选择器只允许选有权管理授权的目录；子目录不提供单独 ACL 入口。

### 2.5 文件锁定与解锁（P0）

- 列表/详情显示锁定图标、锁定人、锁定时间。
- 锁定：行菜单 → 锁定文件 → 服务端原子创建 → UI 更新为已锁定。
- 解锁：仅锁定人可见"解锁"按钮；管理员可在文件详情/管理入口执行管理员解锁；其他用户只见锁定信息。

| 场景 | 结果 |
|---|---|
| 锁定人编辑并保存 | 允许（仍查写权限与版本） |
| 其他用户修改 | 拒绝写入 |
| Agent 修改锁定文件（v2） | 按相同规则拒绝 |
| 锁定人离线/退出 | 保持锁定 |
| 管理员解锁 | 解除锁定，不自动授予写权限 |

### 2.6 版本历史与回收站（P0）

版本历史（文件详情右侧抽屉）：

- 列表：版本号、修改时间、修改人、文件大小、当前版本标记。
- 查看历史版本；恢复前提示"将创建新版本"。

回收站（一级导航页）：

- 列表：名称、原目录、删除时间、删除人、剩余保留天数。
- 操作：恢复、永久删除、批量恢复、批量永久删除；默认保留 180 天。
- 恢复冲突（同名/路径占用）：提供"重命名恢复（追加 (n)）/ 选择其他位置 / 取消"。
- 超期内容由后台任务清理（含索引，v2）。

### 2.7 分享与目录网站开放（P1/P0 边界：均为 P1 的 M3）

两个功能入口分离，不合并成模糊的"公开"按钮。

文件分享：

- 创建弹窗：密码、有效期、访问次数、是否仅预览 → 生成链接。
- 分享记录列表：链接状态（有效/已过期/已撤销）、访问次数、撤销、复制链接。
- 分享审计（管理员可见）。

目录网站开放：

- 目录行菜单/详情 → 开启网站开放。
- 显示 16 位标识与完整访问地址 + 复制按钮；访问策略（公开 / 需登录，可配）。
- 开启/关闭开关；关闭后立即失效（服务端拒绝旧地址）。
- 未配置发布域名时：入口置灰 + 提示"管理员未配置发布域名"。

### 2.8 用户管理与 LDAP（P0，管理员）

- 标准后台表格：顶部标题 + "新建用户" + "LDAP 导入"；筛选（用户名、来源、角色、状态）。
- 表格列：用户名、来源（本地/LDAP 标记）、角色、状态、创建时间、**配额（已用 / 上限，`不限` 为默认）**、操作。
- 操作列：**只常显「编辑」**，其余收进行尾「⋯」下拉菜单（重置密码 / 存储配额 / 禁用账号·启用账号 / 删除用户），避免操作列过宽。
  - 禁用/启用**一键生效，无确认框**；配额弹窗填 MB，留空 = 不限制；删除用户需**二次确认**（红色警示 + 必须手动输入用户名，输入一致才可点「永久删除」；不能删除自己）。
  - 下拉菜单统一 portal 到 `body` 并做视口内翻转，避免被桌面窗口的 `backdrop-filter` 包含块裁切。
- 配额超限时上传/保存/复制被拒（413 `QUOTA_EXCEEDED`）；前端在开始上传前用 `/auth/me` 的配额快照预检，避免白传整个文件。
- LDAP 导入结果页：导入成功数、跳过数（冲突）、失败原因。
- LDAP 规则 UI 明确：不在系统内修改 LDAP 密码；LDAP 删除不联动删除本地用户。

### 2.9 管理页（P0，管理员）

- 审计日志：列表 + 筛选（时间/类别/操作人/资源）+ CSV 导出。
- 系统设置：上传上限、回收站保留天数、版本保留数、发布域名（v2：LLM/嵌入模型配置）。
- 索引状态页：v2 实现。

## 3. 实施优先级

| 阶段 | 页面 |
|---|---|
| P0 | 文件管理首页、权限弹窗、锁定状态、版本历史、回收站、用户管理、登录/引导 |
| P1 | 在线编辑页（ranuts/document 同源 iframe）、文件分享、目录网站开放、预览页 |
| P2 (v2) | 文档页 AI 助手面板、全应用 Agent 页、内容搜索结果、索引状态 |

先做扎实三个核心体验：**文件管理首页 + 编辑器/AI 助手 + 权限/锁定弹窗**——它们确定整个产品的视觉体系与主要交互模式，后续页面沿用同一套设计语言。

## 4. 前端编码要求

1. 编码前先读 fe-init / fe-coding Skills 并遵循（已固化进 `docs/03-conventions.md` §4）。
2. 先完成全局布局、设计 Token、导航、按钮、表格、弹窗、抽屉等基础组件，再开发业务页面。
3. 文件列表、文件详情、编辑器、权限弹窗、锁定状态使用统一的数据模型与交互规范。
4. 所有加载中、空态、错误态、无权限态、锁定态都要实现。
5. 用真实可交互页面验证布局，不交付静态截图。
6. 编辑器与 Agent 面板独立布局适配；窄屏右侧面板转抽屉。
7. 锁定/权限/分享/写回全部由后端强制校验。
